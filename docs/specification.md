# Спецификация системы

## Целевая аудитория

| Роль | Задачи |
| :--- | :--- |
| Официант | Приём заказов, расчёт гостей, управление столиками |
| Повар | Просмотр очереди заказов, отметка готовности |
| Администратор | Управление меню, складом, сотрудниками |
| Управляющий | Отчёты по выручке, расчёт зарплаты |

## Основные функции

1. Создание заказа с привязкой к столику
2. Автоматическое списание продуктов по техкартам
3. Управление складом с цветовой индикацией
4. Расчёт зарплаты с учётом KPI
5. Административная панель управления
